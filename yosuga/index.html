How it works

保存した日から、
読む日まで。

やることは、追加と、日付を決めることだけ。あとは決めた日に、Yosuga が戻してきます。

01 · Add

共有ボタンから、追加。

Safari でも、どのアプリでも。共有ボタンから Yosuga を選ぶだけです。タイトルとサイト名は自動で入ります。

  • 種類（読む・見る・行く・買う・作る）は URL から推測
  • コピーした URL をアプリで貼り付けても追加できる

02 · Date

いつ読むかだけ、決める。

今日・明日・週末。選んだ日の Up Next に並びます。決めるのはあとでも構いません。日付のない保存は、別の欄で待っています。

  • 日付は「明日」ではなく 10/10（土）のように具体的に
  • 読む・見るは2週間先まで、行く・買うは3か月先まで

03 · Notify

その日に、1回だけ届く。

予定のある日に、1回だけ通知します。通知には記事名が出るので、開かなくても何の日か分かります。はじめは 9:00。時刻は設定で変えられます。

  • 通知を切っていても、ウィジェットで今日の分が見える
  • 予定のない日は、何も届かない

04 · Done

読んだら、済み。

アプリの中で開いて、そのまま「読んだ」。確認は出さず、間違えたらすぐ取り消せます。今日の分が終われば「今日はここまで」と次の日付を出すだけです。

  • ボタンは種類ごとに：読んだ・見た・行った・買った・作った
  • 済んだものは30日たつと自動で消える

Yosuga Pro

最後まで読むための、
道具を足す。

追加・日付・通知・ウィジェットは、ずっと無料。保存の数にも上限はありません。Pro は、読み切るための道具です。

  • Reader
    リーダー広告やメニューを外して、本文だけを読む。
  • Listen
    聴く移動中や家事のあいだに。読んでいる文を追いかけて強調します。
  • Resume
    続きから前回やめた所から開きます。
  • Notify+
    くわしい通知平日と休日、種類ごとに時刻を変えられます。
  • Stats
    記録12週の記録と、いつなら済ませられるかの一言。
  • Offline
    オフラインとバックアップ電波がなくても読めて、データを書き出せます。

Privacy

保存したものは、
あなたの端末に。

No server

アカウントは要りません

独自のサーバーを持たず、登録もありません。保存したものは端末の中にあります。

No tracking

追跡しません

行動を追う解析ツールも、広告ネットワークも使いません。通知はすべて端末内で組みます。

iCloud

iCloud 同期は無料

あなたの iCloud で iPhone・iPad・Mac の間を同期します。データを預かることはありません。
